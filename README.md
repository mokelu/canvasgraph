# canvasgraph
Canvasgraph is an agnostic modern general purpose IDE and computational notebook. Think VScode but the center can be a chart, kanban, notebook, markdown, spreadsheet, app, calendar, document editor, games, etc. Anything you can think of.

There are 0 design decisions, you are free to use whatever design comes to your mind. Canvasgraph supports, a host of libraries.
You can see visit the appstore to see so many of these libraries
