# Canvasgraph

**Demo URL:** https://canvasgraph.riemannresearch.com

Canvasgraph is a **framework-agnostic, modern, general-purpose computational notebook and IDE**.

Think **VS Code**, except the center of the workspace can be almost anything: a chart, Kanban board, notebook, code editor, Markdown editor, spreadsheet, app, calendar, document editor, game, or anything else you can imagine.

Canvasgraph does not prescribe a particular interface, library, workflow, or way of working. There is **nothing fixed**. You are free to choose what belongs in your workspace, how it behaves, and which technologies you want to use.

Canvasgraph supports a wide range of libraries and technologies, allowing you to create and combine different kinds of experiences **immediately and without friction**.

Explore the App Store to discover the libraries and capabilities available:

**App Store:** https://trunk.riemannresearch.com

## AI Playground

Canvasgraph is also an **AI playground**.

The idea is simple: instead of AI being confined to a chat window, **AI can act inside the environment itself**.

The Canvasgraph world can contain a code editor, file editor, video editor, charts, documents, applications, notebooks, and many other tools. It also has an event-processing layer that can understand what is happening inside the environment; for example, when something is clicked, changed, created, moved, or completed.

This gives AI an environment it can actually **see, understand, and act within**.

For example, you could tell the AI:

> "Write this file."

The AI can then write the file directly in the workspace or on your system.

Or:

> "Create a chart from this data and put it beside the notebook."

The AI can create the chart, place it in the workspace, and use the surrounding notebook, files, and other available context as part of the task.

Canvasgraph also has its own programming layer, which means the AI is not limited to producing text. It can **create things, modify things, connect things, and respond to events** inside the environment.

The goal is to make Canvasgraph feel less like an application containing an AI and more like a **world in which AI can operate**.

In that sense, Canvasgraph is evolving toward an **AI operating environment**, a place where software, data, tools, events, and AI agents can all exist and interact in the same space.
